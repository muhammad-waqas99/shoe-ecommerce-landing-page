# Sole — Shoe E-Commerce Landing Page

A modern and responsive shoe e-commerce landing page built with **Bootstrap, HTML, CSS, and JavaScript**, featuring a premium-inspired design and responsive layouts.

> **SMIT Assignment:** This project was developed as part of an assignment at **Saylani Mass IT Training (SMIT)** to practice using Bootstrap components and utilities while building a responsive e-commerce landing page.


A modern shoe store landing page featuring a hero carousel, product sections, categories, promotional content, and a responsive footer.

## Features

* Responsive e-commerce landing page
* Bootstrap components and utility classes
* Hero carousel with custom controls
* Product cards
* New collection section
* Promotional banner
* Horizontal category section
* Newsletter subscription UI
* Responsive footer
* Custom typography
* Hover effects and transitions
* Mobile-friendly design

## Fonts

The project uses Google Fonts for its visual typography:

* **Audiowide** — Logo
* **Space Grotesk** — Headings
* **DM Sans** — Navigation and body text
* **Barlow Condensed** — Prices and numerical content

## Bootstrap Usage

Bootstrap is used throughout the project for:

* Navbar
* Carousel
* Cards
* Buttons
* Flex utilities
* Spacing utilities
* Typography utilities
* Responsive utilities

Custom CSS is used alongside Bootstrap for the project's colors, typography, sizing, positioning, animations, hover effects, and other design-specific styling.

## Responsive Design

The landing page is designed to adapt to:

* Mobile devices
* Tablets
* Desktop screens
* Large screens

Bootstrap utilities are combined with custom media queries where required for the design.
